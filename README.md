# 🧺 Amih Laundry Management System

**Sistem Informasi Manajemen Laundry Berbasis Web**

Amih Laundry Management System merupakan aplikasi berbasis web yang dirancang untuk membantu pengelolaan operasional laundry, mulai dari data pelanggan, layanan laundry, transaksi, pembayaran, proses pencucian, hingga laporan keuangan.

Aplikasi ini dikembangkan untuk mendukung proses pengelolaan laundry agar lebih terstruktur, efisien, dan mudah dipantau.

## 📖 Tentang Project

Dalam operasional laundry, pencatatan transaksi dan pengelolaan data yang masih dilakukan secara manual dapat menyulitkan pencarian informasi serta pembuatan laporan.

Amih Laundry Management System dikembangkan sebagai solusi digital untuk membantu mengelola data dan aktivitas laundry dalam satu aplikasi berbasis web.

Sistem ini memiliki beberapa jenis pengguna dengan hak akses berbeda sesuai tugas dan tanggung jawab masing-masing.

## ✨ Fitur Utama

### 👤 1. Admin
- Mengelola data pelanggan.
- Mengelola layanan laundry.
- Mengelola data pengguna.
- Mengelola biaya operasional.
- Mencari layanan laundry.
- Mengakses laporan pengelolaan laundry.

### 💳 2. Kasir
- Mengelola transaksi laundry.
- Memproses pembayaran.
- Melihat riwayat transaksi.
- Mencari transaksi.
- Mengelola proses pengambilan cucian.

### 🧺 3. Staff Laundry
- Melihat daftar cucian.
- Melihat detail transaksi cucian.
- Memperbarui status proses pencucian.
- Menambahkan catatan proses cucian.

### 📊 4. Owner
- Melihat dashboard bisnis.
- Memantau pendapatan dan biaya operasional.
- Mengetahui keuntungan berdasarkan data transaksi dan biaya.
- Melihat laporan berdasarkan periode.
- Mengunduh laporan dalam format PDF.

### 🧾 5. Customer
- Melihat informasi transaksi laundry miliknya.
- Memantau status cucian.
- Melihat informasi pembayaran.
- Mengunggah bukti pembayaran apabila menggunakan metode pembayaran yang memerlukannya.

## 🛠️ Teknologi yang Digunakan

- **Backend:** Laravel
- **Bahasa Pemrograman:** PHP, JavaScript
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL/MariaDB
- **Version Control:** Git dan GitHub

## 🔄 Alur Sistem

1. Kasir memasukkan data transaksi laundry.
2. Sistem menyimpan informasi transaksi.
3. Pembayaran diproses sesuai metode yang tersedia.
4. Staff Laundry memperbarui status pengerjaan cucian.
5. Kasir membantu proses pengambilan cucian.
6. Admin dan Owner dapat mengakses data sesuai hak aksesnya.
7. Owner menggunakan laporan untuk memantau pendapatan, biaya, dan keuntungan.

## 🎯 Tujuan Pengembangan

- Mendigitalisasi pengelolaan data laundry.
- Mempermudah pencatatan dan pencarian transaksi.
- Membantu pemantauan proses pencucian.
- Mempermudah pengelolaan pembayaran dan pengambilan cucian.
- Membantu penyusunan laporan pendapatan, biaya operasional, dan keuntungan.
- Menerapkan pengembangan aplikasi web menggunakan Laravel dan database relasional.
